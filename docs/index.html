How it works

Sync without the cloud

Ampme turns one phone into a tiny local media server. The rest is timing — the good kind.

1

Host a session

Pick a song — or broadcast any audio your phone is playing, from any app. Your device serves the audio straight over your WiFi.

2

Friends join

Sessions appear automatically on nearby phones, or join by code / QR. A control channel links every listener to the host.

3

Stay perfectly in sync

An NTP-style clock sync estimates the offset between devices. Playback fires from a precise timer — and a ~30 ms drift correction keeps it locked, song after song.

Features

Built for real listening rooms

Everything runs on your local network. Nothing is uploaded, logged, or monetized.

New

Broadcast device audio

Whatever your phone is playing — Spotify, YouTube, a game, a video — gets streamed to every listener. No file selection needed.

Amplify the room

Broadcast your microphone live — lectures, singalongs, commentary — on every platform, instantly.

Tight sync, all night

Clock-offset estimation plus continuous drift correction keep phones within ~30 ms of each other — inaudible, even on beats.

No cloud, no account

Audio never leaves your WiFi. Private by design — there's no server to trust, no sign-up, no tracking.

Auto-discovery

Nearby sessions show up on their own via UDP beacon. Join with one tap — no typing IP addresses.

Join by code or QR

Type the host's code or point your camera at the QR — connected in seconds, even when discovery can't reach.

Web app

Try Ampme in your browser

The full app runs on the web too — host a session with WebRTC streaming (30–80 ms on a LAN) or join any session. No install; works on Windows, Mac, Chromebook, and phones.

Open the web app

Browsers block secure (HTTPS) pages from reaching devices on your WiFi, so this hosted preview renders the app while the live host & join flow runs from your LAN. One command on any computer on the same network:

dart run tool/web_relay.dart
Then open http://<lan-ip>:8080 (the relay prints it), click Open the web app, and host — friends join by the code it shows, from the browser or the native apps.
FAQ

Questions, answered

Why can't I find it on the Play Store?

Ampme is a from-scratch side project, distributed directly as an APK for now. That keeps it free and lets you install it in seconds — just allow "install unknown apps" for your browser or file manager when Android asks.

Does everyone need the app?

Yes — each phone runs Ampme and joins the host's session. The host broadcasts over WiFi; listeners just need the app (and the host's code, or auto-discovery finds them).

Does it work over the internet?

No. Sessions are local-network only — all devices must be on the same WiFi (or one phone's hotspot). That's the trade-off that makes perfect sync and zero cloud possible.

Why "Android 10+" for device audio?

Broadcasting what your phone is playing uses Android's MediaProjection capture API (introduced in Android 10). Older Android versions can still host file-based and microphone sessions.

Can I broadcast Spotify?

Mostly yes — but some apps (Spotify among them) can opt out of audio playback capture, in which case you'll capture silence. DRM-protected streams are always excluded. File playback and the microphone work with everything.

What about Windows, macOS, or web?

The app also runs on Windows (host or listener) and in the browser (join, or host via WebRTC). iOS can join too when available. This page ships the Android build plus a hosted web preview — the same release contains everything else.
